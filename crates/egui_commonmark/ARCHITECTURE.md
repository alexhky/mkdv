# Architecture

## Crates

- `egui_commonmark_extended`
- `egui_commonmark_macros_extended`
- `egui_commonmark_backend_extended`

### egui_commonmark_extended

This is the main crate. It depends on `egui_commonmark_backend_extended` and can
expose `egui_commonmark_macros_extended` through the `macros` feature. The fork
also contains mkdv's search highlighting, heading-position tracking,
typography, resizable tables, emoji, math, and Mermaid integration.

### egui_commonmark_macros_extended

This is a proc-macro crate. It depends on
`egui_commonmark_backend_extended`.

### egui_commonmark_backend_extended

This crate contains code shared between the extended egui_commonmark
crates. The code in this crate is also used by the code generated by
`egui_commonmark_macros_extended`. As a result the visibility of most items in it is `pub`
by default. Since a user should not directly rely on these APIs most elements
are hidden from the documentation.

`egui_commonmark_extended` re-exports some of its items, so care must be taken to ensure
that no implementation details are accidentally exposed.
